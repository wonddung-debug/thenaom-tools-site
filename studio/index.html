영상 통합 작업실

Thenaom Video Studio — 운영자 본인 채널 전용 개인 PC 프로그램

Developed with YouTube API Services · YouTube API 서비스 사용

무엇을 하는 프로그램인가요?

Thenaom Tools 운영자가 직접 기획·제작한 영상을 운영자 본인이 소유·관리하는 유튜브 채널에 올릴 때 쓰는 윈도우 PC 프로그램입니다. 외부 사용자에게 제공하거나 판매하지 않습니다.

A Windows desktop tool used only by the operator of Thenaom Tools to upload videos the operator produced to YouTube channels the operator owns and manages. It is not offered to the public.

YouTube API로 하는 일

  1. 운영자가 Google 계정으로 로그인해 자기 채널 접근을 허락합니다 (OAuth 2.0).
  2. 완성된 영상 파일을 제목·설명·태그·공개 설정과 함께 올립니다 (videos.insert).
  3. 썸네일을 지정합니다 (thumbnails.set).
  4. 필요하면 재생목록에 넣고, 올린 영상 정보를 고칩니다 (playlistItems.insert, videos.update).
  5. 올라간 영상의 주소와 상태를 확인해 작업 기록에 남깁니다 (channels.list, videos.list).

Sign in with Google (OAuth 2.0) → upload the finished video with title, description, tags and privacy setting → set the thumbnail → optionally add to a playlist or update metadata → read back the video URL and status for the operator's own work log.

데이터는 어디에 있나요?

로그인 정보(접근 토큰)와 작업 기록은 운영자 PC 안에만 저장됩니다. 별도 서버로 보내거나 다른 사람·회사와 공유하지 않습니다. 자세한 내용은 개인정보처리방침을 보세요.

Tokens and work logs stay on the operator's own computer. Nothing is sent to any other server or shared with third parties. See the Privacy Policy.
