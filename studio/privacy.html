1. 이 방침이 적용되는 프로그램

"영상 통합 작업실"(이하 "프로그램")은 Thenaom Tools 운영자와 함께 일하는 소수의 사람(5명 이하)이 자신이 소유하거나 채널 주인의 허락을 받아 관리하는 유튜브 채널에 영상을 올리기 위해 쓰는 무료 윈도우 PC 프로그램입니다. 프로그램은 YouTube API 서비스를 사용합니다. 프로그램은 일반에 공개·판매되지 않습니다.

This policy covers "Thenaom Video Studio", a Windows desktop tool that uses YouTube API Services. It is used free of charge by the operator of Thenaom Tools and a few collaborators (5 or fewer) for YouTube channels they own or manage with the owner's permission. It is not offered or sold to the public.

2. YouTube 약관과 Google 개인정보처리방침

프로그램은 YouTube API 서비스를 사용하므로, 프로그램을 쓰는 사람은 YouTube 서비스 약관에 동의하게 됩니다. YouTube API 서비스를 통해 처리되는 정보에는 Google 개인정보처리방침(http://www.google.com/policies/privacy)이 적용됩니다.

By using this tool you agree to be bound by the YouTube Terms of Service. Information processed through YouTube API Services is also subject to the Google Privacy Policy.

위 정보는 영상 업로드·썸네일 지정·재생목록 추가·영상 정보 수정, 그리고 사용하는 사람 본인의 작업 기록에만 씁니다. 개발자(Thenaom Tools)를 포함해 어떤 서버로도 보내지 않고, 광고·분석·판매 목적으로 쓰지 않으며, 제3자와 공유하지 않습니다. 법률상 요구가 있는 경우를 빼고는 누구에게도 제공하지 않습니다.

It is not sent to any server (including the developer's), not used for advertising or analytics, not sold, and not shared with any third party except where required by law.

The tool does not store, access or collect cookies or other identifiers on users' devices, and does not send device information anywhere.

6. 지우기와 권한 취소

  • 프로그램의 [연결 끊기] 버튼을 누르면 해당 채널의 토큰과 API로 받은 정보가 PC에서 지워집니다.
  • 채널 주인을 포함해 접근을 허락한 사람은 누구나 언제든지 Google 보안 설정의 서드파티 앱 접근 권한 페이지에서 이 프로그램의 접근을 취소할 수 있습니다.
  • 지우기를 원하면 아래 이메일로 요청할 수 있으며, 7일 안에 처리합니다.

Press "Disconnect" in the tool to delete the stored tokens and API data for that channel. Anyone who granted access, including channel owners, can revoke it at any time via the Google security settings page. Deletion requests sent to the contact below are handled within 7 days.
